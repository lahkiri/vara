# Computer Use في Vara — القدرة الأصلية

> v0.5.0 · **المرجع الكامل للتحليل:** `download/vara-computer-use-integration.md` (خارطة الدمج من تحليل الـ MCP)
> **المصدر:** MCP خاص بالمالك (38 أداة، Windows، Python) — نُقلت **فلسفته** إلى نواة Vara، لا أدواته فقط.

## القرار المعماري

القيمة الحقيقية للـ MCP ليست في الأدوات بل في **الانضباط البنيوي**: حلقة see→act→confirm إجبارية، focus-first، منع النقر الأعمى، بوابات هدم ثنائية، والاستجابة-كإرشاد. لذلك النقل تم على ثلاث طبقات:

```
النموذج (خيط الشات)          — يقترح فقط: [[sys]] computer_use {sequence}
        │ موافقة المالك (بطاقة)
        ▼
 vara-core::computer_use      — ActLoop: تحقق بنيوي + سُلّم صلاحيات + grounding + journal
        │ عقد ComputerUseAdapter
        ▼
 المحوّلات                    — Sidecar (MCP stdio، Phase 1) / Mock (اختبارات) / Rust-native (Phase 2)
```

## سُلّم الصلاحيات

| المستوى | الفئة | أمثلة | البوابة |
|---|---|---|---|
| L0 | قراءة | screenshot, verify, wait | تلقائي |
| L1 | إدخال قابل للتراجع | click, type, hotkey عادي, focus | إعداد `allow_computer_use` |
| L2 | دورة حياة/هدم | close_window, close_app, alt+f4 | `computer_use_allow_close` + موافقة صريحة |

القواعد البنيوية التي يفرضها الـ ActLoop نفسه (لا نصائح للنموذج):
1. **لا نقر أعمى**: إحداثيات بلا لقطة سابقة في نفس التسلسل = رفض فوري.
2. **الهدم جاف افتراضيًا**: `close_*` بلا `confirm=true` لا يفعل شيئًا ويعيد المعاينة.
3. **التأكيد بنيوي**: تسلسل ينتهي بفعل غير مُتحقق منه يحصل على لقطة إثبات أخيرة.
4. **تصحيح محدود**: إعادة واحدة فقط، وفقط إذا فشل قبل أي فعل مُعدِّل.

## عالم الاختبار (MockComputerUse)

شاشة ويندوز افتراضية حتمية تحاكي فشل الواقع: إطارات ستاتيكية من اللوحات المتحركة (انضباط settle)، سرقة تركيز (تشخيص `active`)، رفض النقر الأعمى، وtyping بلا تركيز يفشل بإرشاد. **9 سيناريوهات** في `crates/vara-core/tests/computer_use_harness.rs` = عقد الـ MCP الأصلي (13 اختبار) منقول ومطوّر.

## الـ harness — وجهان

- **وجه الكيان:** السيناريوهات أعلاه تقيس `verify_discipline` و`grounded_clean` وحدود التصحيح — لاحقًا ستقيّم تخطيط الكيان نفسه (LLM-in-the-loop) بمقاييس الانضباط نفسها.
- **وجه الأبحاث:** `scripts/vara_harness_v2.mjs` — منفّذ حملة الأذرع الأربعة المسجّلة مسبقًا (EXPERIMENT_DESIGN.md): 24 تشغيلة بميزانية 90k token صارمة، نموذج مسمى في كل صف، أدوات بحث/fetch حقيقية، وسجل سبب التوقف. مستعاد لأنه كان مُشارًا إليه وغير مرفوع. مع `check_provenance.mjs` كبوابة M1 مستقلة.

## Phase 2 (مخطط)

نقل كامل إلى Rust: `enigo` (إدخال) + `windows-rs` (نوافذ) + DXGI (لقطة) + **Windows.Media.Ocr** (OCR بلا Tesseract) + UIA لاحقًا — كلها خلف نفس عقد `ComputerUseAdapter` فلا يتغير شيء فوقه. التفاصيل في `sidecar/README.md`.
